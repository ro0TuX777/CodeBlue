Understanding Taint Analysis

Sources

Entry points where untrusted data enters the application (user input, files, network data).

Sinks

Sensitive operations that could be exploited if they receive untrusted data (SQL queries, file operations).

Sanitizers

Functions that clean or validate data, breaking the taint flow and reducing risk.

Taint Paths

Data flow paths from sources to sinks, representing potential security vulnerabilities.
